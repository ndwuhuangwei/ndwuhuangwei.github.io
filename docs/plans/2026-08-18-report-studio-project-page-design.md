### 3. 技术亮点

以招聘阅读优先的五组结构呈现，同时保留可检索的主流技术名称：

1. **Agent 编排与 Human-in-the-loop**：自研 DAG 工作流、拓扑校验、内容寻址 Checkpoint、断点恢复；Multi-Agent 学术沙龙；ReAct、原生 Function Calling；LangGraph 报告编辑 Agent；需求问询、专家确认、逻辑拓扑编辑和计划审阅等 HITL 节点。
2. **真实文献库与 Agentic RAG**：AceMap 文献数据库与用户知识库并行；PDF、DOCX、Markdown、TXT 结构化解析和上下文化分块；BM25 + BGE-M3 稠密检索、RRF 融合、BGE Cross-Encoder 重排；多轮定向检索与 Tavily 联网检索；服务不可用时显式降级。
3. **证据约束的规划与写作**：从需求生成可执行、可编辑报告拓扑；结构化论文证据提取；来源 ID、出处类型和混合来源追踪；按首次出现顺序编排引用与参考文献，保留 DOI；数据驱动图表进入正文。
4. **长报告生成工程**：DeepSeek 系列模型经 OpenAI-compatible 接口按阶段路由；快/深思模式、模型降级、上下文预算与分层压缩；自适应并发、章节并行生成、分阶段缓存与恢复，避免长任务因单点失败整体重跑。
5. **可交付产品闭环**：账户与会话持久化、跨会话知识库复用、可编辑报告预览；报告编辑 Agent 通过 diff 和修订号保护并发编辑；中英双语界面；Markdown 与 DOCX 导出。

不使用仅因出现在依赖文件中、但 Report Studio 路径未实际采用的技术作为亮点。例如，不将 FastAPI 描述成 Report Studio Web 服务实现，也不声称使用向量数据库。
